## Notes

- **Bedrock, Claude models:** Anthropic's prices are assumed; check your Bedrock rates.
- **Bedrock, Nova:** 5-minute lifetime only, system and messages only, at most 20K cached tokens; prices are not built in, set --price.
- **OpenAI, GPT-6.2 and later:** 12-hour lifetime is available in the Responses API only; top-level `instructions` are placed after the input, never cached and billed in full (finding CP010); a cache write also makes every earlier message ending in that prompt readable.
- **OpenAI, GPT-5.6 to GPT-6.1:** 12-hour lifetime is available in the Responses API only; a cache write also makes every earlier message ending in that prompt readable.
- **OpenAI, GPT-5.5 and earlier:** caching is automatic on this model with no write fee; the one setting is prompt_cache_retention. Lifetimes are the typical values OpenAI documents (5 to 10 minutes in memory, about 30 minutes with 24h retention), not guarantees.
- **Gemini:** the lifetime of Gemini's implicit caches is not documented, so this forecast assumes 5 minutes; cache hits are assumed to be billed at the listed cached-input price (Vertex AI list prices); explicit caches (cachedContents) are not modelled; Gemini 4 gains a cache-write price on 12 January 2027, which is not modelled.
